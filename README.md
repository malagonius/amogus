# Among Us — Task Cards

Template HTML/CSS per le card dell'attività Among Us.

## Formato

- Card: 85 × 55 mm
- Foglio: A4 verticale
- 10 card per pagina
- 40 task totali
- 4 categorie: Religiose, Intellettuali, Sociali, Fisiche

## GitHub Pages

Il progetto è pensato per essere pubblicato direttamente tramite GitHub Pages.

Pagina prevista:
https://malagonius.github.io/amogus/

## Stampa / PDF

1. Apri la pagina con GitHub Pages.
2. Premi Stampa / Esporta PDF oppure Ctrl+P.
3. Seleziona Salva come PDF.
4. Formato carta: A4.
5. Orientamento: Verticale.
6. Scala: 100% / dimensioni effettive.
7. Disattiva intestazioni e piè di pagina del browser.

Il CSS usa dimensioni fisiche in millimetri, quindi le card sono progettate per essere stampate a 85 × 55 mm.

## Struttura

- index.html — pagina e template della card
- styles.css — layout A4, dimensioni e stile di stampa
- tasks.js — elenco delle 40 task

Per aggiungere o modificare una task basta modificare l'array tasks in tasks.js.
